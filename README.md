
# QA Project: SauceDemo

## Project Goal
Apply quality assurance techniques to test a web application end to end:
test planning, test design, execution, defect reporting, exploratory testing,
API testing, automation and reporting.

## Application Under Test
- **Web app:** https://www.saucedemo.com
- **API:** https://dummyjson.com

## Tools
- GitHub (version control and issue tracking)
- Excel / Markdown (test cases, reports)
- Postman (API testing)
- Playwright or Selenium (automation)
- Browsers: Chrome, Firefox, Edge

## Techniques Used
Equivalence Partitioning, Boundary Value Analysis, Decision Tables,
State Transition Testing, Exploratory Testing, Regression Testing,
Requirements Traceability Matrix
